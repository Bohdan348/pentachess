# PentaChess — Five Kings

Рабочий MVP шахмат на пять игроков: React + TypeScript, SVG-доска, серверный графовый движок, комнаты, гостевые сессии, случайные места, Ready, таймеры, история, чат и переподключение.

## Запуск

```bash
npm install
npm run build
npm start
```

Открыть http://localhost:3000. Для игры на разных устройствах запустить сервер на доступном хосте и проксировать HTTPS и `/ws`. `PORT` задаёт порт. Нужен Node.js 22+. Комнаты локального сервера сохраняются в `.data/rooms.json` атомарно, в том числе после рестарта.

По умолчанию открывается практика: все пять цветов управляются одним пользователем, без AI. Для multiplayer: «Играть с друзьями» → имя → создать комнату → скопировать приглашение → открыть ссылку в пяти разных браузерах/профилях → каждый нажимает «Я готов». Цвета распределяются после готовности всех игроков. Вкладки одного профиля используют одну гостевую сессию.

## Правила MVP

См. [BOARD.md](BOARD.md): 200 клеток, пять симметричных секторов по 8×5. Логика никак не зависит от SVG. Сам центр — декоративное пространство, центральная игровая зона — внутренний ряд каждой секции. Проверенные сервером ходы передаются клиенту. Все виды фигур, выбор направления пешки, превращение Q/R/B/N, запрет хода под шах, немедленный мат любого игрока, исчезновение армии, пропуск уничтоженного игрока, Last King Standing и места 1–5.

Контроль времени: 10:00 + 3 секунды, либо 45/20/8 секунд на ход. Часы и отключение проверяются сервером. Переподключение по сохранённому временному токену, 90 секунд до исключения. В hosted-варианте проверки запускаются запросами активных клиентов; в Node — также серверным тиком для подключённых комнат. Пока никто не подключён, позиция сохраняется; по следующему запросу применяются истёкшие лимиты.

Нет рокировки и взятия на проходе. Пат выводит игрока из партии. Центральные разветвления и коневой граф — экспериментальные правила этой версии, а не стандарт FIDE. Аккаунты, рейтинги и друзья не реализованы: основная задача MVP — партия пяти гостей. Можно играть без регистрации.

## Архитектура

- `src/engine.ts`: граф, атаки, допустимые ходы, шах/мат, порядок ходов, часы, статистика.
- `src/rooms.ts`: команды сервера, сессии, случайные места, готовность, reconnect, optimistic concurrency.
- `src/server.ts`: Node + WebSocket, HTTP API, атомарный файловый адаптер.
- `src/worker.ts`: hosted HTTP API + D1, условные SQL-обновления по версии. Клиент синхронизируется каждые 2 секунды; попытка WebSocket автоматически уступает HTTP.
- `src/App.tsx`: React, адаптивная SVG-доска, вращение, серверная подсветка, история, чат.
- `drizzle/`: миграции SQL, применяемые Sites при публикации.

Хранилище комнат отделено интерфейсом `Store`. PostgreSQL не подключён; это задача для следующего production этапа вместе с аккаунтами, rate limiting, удалением старых комнат и отдельным планировщиком. Временные гостевые токены не включаются в публичное состояние или ссылки. Клиент не изменяет серверную позицию: авторство, очередность, допустимость и безопасность короля проверяются сервером. Сравнение версий предотвращает перезапись позиции параллельными запросами.

## Публикация

Sites публикует приватную версию на Cloudflare Workers с D1. Это другой runtime относительно Node + WebSocket; игровой движок общий. Приватная публикация доступна владельцу. Для игры с друзьями за пределами private-доступа используйте собственный Node-сервер или отдельно настройте аудиторию сайта.
